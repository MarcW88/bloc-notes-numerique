# Guide explicatif technique

Utiliser ce parcours pour expliquer une technologie, une mesure ou un fonctionnement.

## Pré-analyse spécifique

- Définir précisément le concept et les termes voisins souvent confondus.
- Séparer principe physique, implémentation logicielle et conséquence pour l’utilisateur.
- Privilégier documentation technique, standards et publications primaires.
- Vérifier unités, conditions de mesure et différences entre générations de produits.

## Architecture recommandée

1. définition courte ;
2. fonctionnement par étapes ;
3. conséquences pratiques ;
4. avantages et limites symétriques ;
5. variations selon les technologies ou produits ;
6. critères permettant d’interpréter une fiche technique ;
7. questions complémentaires utiles.

Éviter les analogies trompeuses. Lorsqu’une simplification est nécessaire, signaler ce qu’elle laisse de côté.
