# Brand Analysis — `/marques/boox/boox-tab-ultra/`

Date : 9 septembre 2026  
Mode : `AUDIT`  
Type : `PRODUCT`

## Décision

**`LIGHT_UPDATE` — confiance HIGH**

La page garde un rôle autonome : expliquer une famille BOOX très orientée « tablet PC » et positionner le Tab Ultra C Pro face aux modèles BOOX plus récents. Le problème n'est pas la structure mais le cadrage générationnel et la profondeur de comparaison interne à la gamme.

## Valeur déjà présente

- positionnement « tablette PC E Ink » clair ;
- Android 12 traité comme un critère de durée d'usage ;
- clavier avec trackpad, caméra et microSD bien identifiés ;
- section « quand le produit garde du sens » utile ;
- distinction avec Note Air et reMarkable déjà amorcée.

## Vérification factuelle

La page officielle BOOX vérifiée le 9 septembre 2026 confirme que le Tab Ultra C Pro reste officiellement documenté et commandable, avec :

- écran 10,3 pouces Kaleido 3 ;
- Android 12 ;
- 6 Go RAM / 128 Go ;
- caméra arrière 16 MP ;
- microSD ;
- clavier magnétique avec trackpad ;
- Google Play / applications tierces.

Le texte actuel est donc factuellement cohérent. Il faut éviter de le présenter comme retiré du marché tant que BOOX continue à le proposer officiellement.

## Blockers

1. le statut doit être formulé précisément : génération plus ancienne, mais produit encore documenté/commandable selon canal ;
2. le maillage ne renvoie pas vers le hub BOOX, l'avis BOOX ni la page alternatives BOOX ;
3. la comparaison avec Note Air5 C est utile mais encore trop courte pour justifier le choix d'un Android 12 en 2026 ;
4. la page cite Tab X C dans la meta description mais ne développe presque pas le cas où un grand écran 13,3 pouces remplace mieux le Tab Ultra C Pro.

## Cannibalisation avec Note Air / hub BOOX

**PASS AVEC CORRECTIONS.**

- hub BOOX : choisir une famille ;
- Note Air : 10,3 pouces actuel, Android 15, notes/productivité légère ;
- Tab Ultra : logique clavier + caméra + tablet PC, génération Android 12.

Ces rôles sont assez distincts pour conserver les URLs séparées.

## Structure / AI-slop

**PASS.** Le plan « logique tablet PC → specs → vieillissement Android → cas d'usage » est spécifique et non cloné sur Note Air.

## Unknowns

La durée future de support Android/applications tierces ne peut pas être prédite. Il faut parler de risque générationnel, pas annoncer une date d'obsolescence non documentée.

## Actions nécessaires

1. préciser le statut commercial/générationnel ;
2. approfondir le choix Tab Ultra C Pro vs Note Air5 C / Tab X C ;
3. ajouter les liens vers hub BOOX, avis BOOX et alternatives BOOX ;
4. conserver Android 12 comme facteur de décision sans spéculer sur une date de fin de support ;
5. ne pas transformer la page en simple archive d'un ancien modèle.

`brand-content-workflow` en `LIGHT_UPDATE`, puis `PUBLISH_REVIEW`.

La page reste `noindex,follow`.
