# Brand Analysis — `/marques/boox/alternatives/`

Date : 9 septembre 2026  
Mode : `AUDIT`  
Type : `ALTERNATIVES`

## Décision

**`LIGHT_UPDATE` — confiance HIGH**

La page a une intention autonome claire : quitter BOOX lorsque l'ouverture Android et la richesse des réglages créent trop de friction. La structure reste valable, mais les recommandations concurrentes sont insuffisamment sourcées localement.

## Valeur déjà présente

- reMarkable = simplicité ;
- Supernote = organisation spécialisée ;
- Kindle/Kobo = lecture d'abord ;
- section « quand rester chez BOOX » utile pour éviter une recommandation systématique de changement ;
- bons liens vers reMarkable vs BOOX et BOOX vs Supernote.

## Blockers

1. la section Sources est presque exclusivement BOOX alors que la page recommande quatre autres écosystèmes ;
2. Supernote, Kindle et Kobo sont cités sans preuve primaire visible sur cette URL ;
3. la section lecture devrait relier directement vers les hubs Kindle Scribe et Kobo Elipsa ;
4. l'orientation « rester chez BOOX » pourrait renvoyer vers le hub BOOX ou les familles Note Air / Tab Ultra selon la friction rencontrée.

## Factualité

Les claims BOOX sont bien documentés. Les claims concurrents sont cohérents avec les audits récents du cluster, mais doivent être prouvés sur la page avec les sources officielles pertinentes.

## Cannibalisation

**PASS.** La page alternatives ne remplace ni le hub BOOX ni les comparatifs. Elle part d'une raison de sortie de l'écosystème.

## Structure / AI-slop

**PASS.** Malgré une logique commune naturelle aux pages alternatives, le contenu final BOOX est centré sur la complexité Android et la sortie vers des écosystèmes plus spécialisés.

## Unknowns

Aucune alternative ne peut être qualifiée de « meilleure » de façon absolue. La décision reste conditionnelle au problème que l'utilisateur cherche à résoudre.

## Actions nécessaires

1. ajouter une source primaire reMarkable, Supernote, Kindle et Kobo ;
2. ajouter les liens directs vers Kindle Scribe et Kobo Elipsa ;
3. ajouter un chemin de retour vers le hub BOOX / Note Air lorsque changer de modèle suffit ;
4. conserver la section « quand rester chez BOOX ».

`brand-content-workflow` en `LIGHT_UPDATE`, puis `PUBLISH_REVIEW`.

La page reste `noindex,follow`.
