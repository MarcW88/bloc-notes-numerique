# Brand Analysis — `/marques/boox/boox-note-air/`

Date : 9 septembre 2026  
Mode : `AUDIT`  
Type : `PRODUCT`

## Décision

**`LIGHT_UPDATE` — confiance HIGH**

La page a un rôle autonome pertinent autour de la famille Note Air et du Note Air5 C actuel. Elle ne nécessite pas de réécriture profonde, mais elle doit devenir plus utile qu'un sous-résumé du hub BOOX.

## Valeur déjà présente

- identification claire du Note Air5 C comme modèle actuel ;
- caractéristiques décisionnelles bien choisies ;
- explication utile d'Android, de Kaleido 3 et du clavier ;
- limites visibles ;
- séparation correcte avec reMarkable via comparatif.

## Vérification factuelle

La page officielle BOOX vérifiée le 9 septembre 2026 confirme notamment :

- écran 10,3 pouces Kaleido 3 ;
- 300 ppp N&B / 150 ppp couleur ;
- Android 15 ;
- 6 Go RAM / 64 Go ;
- slot microSD ;
- Google Play ;
- clavier cover compatible ;
- Pen3 et fonctions Notes/NeoReader.

Les caractéristiques centrales de la page sont donc `VERIFIED`.

## Blockers

1. le maillage interne est trop faible : un seul lien éditorial vers reMarkable vs BOOX ;
2. la page doit renvoyer vers le hub BOOX, l'avis BOOX et les accessoires pour les questions de gamme, confiance/SAV et compatibilité ;
3. le différentiel Note Air4 C → Note Air5 C est annoncé dans la meta mais peu développé dans le contenu ;
4. la page peut approfondir ce qui est réellement propre au Note Air5 C : Android 15, Smooth refresh/EinkWise, clavier et microSD, sans répéter le hub général.

## Cannibalisation avec le hub BOOX

**PASS AVEC CORRECTIONS.** Le hub répond au choix entre familles BOOX ; cette page doit répondre à « pourquoi choisir la famille Note Air / le Note Air5 C ? ». Le contenu actuel va dans ce sens mais manque encore de profondeur spécifique.

## Structure / AI-slop

**PASS.** Le plan rendu est spécifique au Note Air5 C et n'utilise plus le squelette produit générique complet.

## Unknowns

Les performances réelles d'applications tierces, le confort du clavier et l'autonomie en usage ne peuvent pas être déduits de la fiche officielle. Ne pas les transformer en verdict hands-on sans sources indépendantes.

## Actions nécessaires

1. renforcer le différentiel Note Air5 C vs génération précédente ;
2. ajouter hub BOOX, avis BOOX et accessoires dans le maillage contextuel ;
3. préciser les fonctions réellement spécifiques au modèle actuel ;
4. conserver les limites Android/E Ink ;
5. ne pas dupliquer la vue multi-familles du hub.
