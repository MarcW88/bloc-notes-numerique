# Brand editorial validation

Les fichiers de `.content/brands/` documentent les données et preuves utilisées par les pages `/marques/`.

La présence d'un fichier de données ne constitue pas une validation éditoriale. Avant publication, chaque URL doit passer par `.agents/skills/brand-editorial-publish-gate/SKILL.md` puis recevoir une validation humaine explicite.

Le validateur `validate_brands.py` contrôle uniquement les blockers détectables automatiquement. Il ne remplace pas le publish gate sémantique.
